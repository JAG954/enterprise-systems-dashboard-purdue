# Code of Conduct

## Expected Behavior

This repository is a portfolio and educational project. Contributors and reviewers are expected to communicate respectfully, focus on the work, and give feedback that is specific, actionable, and professional.

## Unacceptable Behavior

Unacceptable behavior includes harassment, discriminatory language, personal attacks, sharing private information without permission, or intentionally disruptive conduct.

## Reporting

If you see a conduct issue, open a private communication channel with the repository owner rather than escalating in public project threads. If this repository is transferred to an organization, use that organization's reporting process.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, documentation, and any project-related communication.
